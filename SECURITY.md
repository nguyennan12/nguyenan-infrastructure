# Security policy

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature, if available for this repository. If it is unavailable, contact the maintainer privately through their GitHub profile before disclosing details publicly. Do not open a public issue or paste credentials, hostnames, private IPs, or exploit details into CI logs.

The proposed v1.0.0 release is the only version currently considered for security fixes; no stable release has been published yet. Security fixes are handled case by case. No response time or support SLA is promised.

Include affected revision, deployment mode, impact, and minimal redacted reproduction steps. For host hardening and operational guidance, see [the operator security guide](docs/SECURITY.md).
