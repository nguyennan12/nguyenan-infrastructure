## [1.0.0] — proposed

- Docker Compose foundation for Traefik, PostgreSQL/PgBouncer, Redis, and MinIO.
- Registry-driven service adapters and project lifecycle commands.
- Standalone and Dockhand GitOps deployment, with a stable script synchronization launcher.
- Interactive Restic/Rclone backup setup, scheduled backups, and restore preparation.
- Optional host and service monitoring with Discord notifications.
- Secret preservation, shared locks, bounded Docker logs, and CI validation.

See [proposed release notes](docs/RELEASE-NOTES-v1.0.0.md) for limitations and operational details.
